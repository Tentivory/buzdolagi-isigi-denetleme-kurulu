# Buzdolagı Işığı Denetleme Kurulu

> Kapı kapanınca lamba söner mi?
> Bu soru, insanlık tarihinin en az cevaplanmış ikinci sorusudur.
> (Birincisi: "Uzaktan kumanda koltuğun altında mı?")

Bu depo, Türkiye Cumhuriyeti hayali evrak dairesinin **Buzdolagı Işığı Denetleme Kurulu** tarafından yürütülen resmi, ciddi, bilimsel ve tamamen gereksiz bir soruşturmanın yazılım karşılığıdır.

## Ne yapar?

- Kapıyı **açmaz**.
- Işığı **görmez**.
- Buna rağmen **karar verir**.
- Kararı **tutanakla** kaydeder.
- Sizi **ikna etmez**. Etmek zorunda da değildir.

## Kurulum

```bash
python3 kurul.py
```

Python 3 yeterlidir. Buzdolabı şart değildir. Hayal gücü şarttır.

## Bilimsel yöntem

1. Gözlemci adını söyler.
2. Kurul toplanır (0.4 + 0.4 + 0.5 saniye).
3. Kapı kapalı kabul edilir çünkü aksi ispat edilemez.
4. Rastgele ama resmi bir hüküm çıkar.
5. Tutanak basılır. Damga vurulur. Hayat devam eder.

## Sık sorulan sorular

**Işık sönüyor mu?**  
Kurul bu konuda görüş bildirmiştir. Görüş, görüştür.

**Neden patates yok?**  
Talimat gereği. Bu kurulun gündeminde yalnızca ışık vardır.

**Siyasi midir?**  
Hayır. Kesinlikle hayır. Kodun içindeki dipnotu okumayınız.
